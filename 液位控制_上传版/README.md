# 基于 STM32 的液位自动控制装置

一个用 **STM32F103C8T6 + HC-SR04 超声波 + TB6612FNG 电机驱动 + 0.96 寸 OLED** 做的液位闭环控制小装置。

装置能实时测量液位、按设定目标自动补排水，并提供 4 种工作模式，用于演示和考核"液位保持在指定刻度"这一任务。

---

## 一、功能特性

| 功能 | 说明 |
|---|---|
| **液位测量** | HC-SR04 超声波测距（TIM2 轮询计时，1µs 分辨率），换算成"相对 0 刻度的液位" |
| **两级滤波** | 中值滤波（7 点）+ 滑动平均（8 点），抑制水面波动与突发错误数据 |
| **假数据判定** | 范围检查（零点 ±8cm）+ 稳定性检查（连续读数一致），泵搅拌水面时自动改用补水量估算 |
| **闭环控制** | 开关式控制 + 预测提前关泵 + 滤波滞后补偿，把液位稳定在目标 ±0.5cm 内 |
| **OLED 显示** | 模式 / 液位 / 水泵状态 / 稳定保持时间 / 当前刻度，共 5 项 |
| **无串口** | 全部信息通过 OLED 显示，不依赖上位机 |

---

## 二、4 种工作模式（KEY1 循环切换）

| 模式 | 屏幕显示 | 行为 |
|---|---|---|
| **模式 1** | `MODE:1` | **标定零点**：把当前水面记成 0 刻度（按 KEY2） |
| **模式 2** | `MODE:2` | **手动**：按 KEY2 开/关水泵 |
| **模式 3** | `MODE:3` | **自动保持 0 位** |
| **模式 4** | `MODE:4` | **自动流程**：0cm 稳 30 秒 → −2cm 稳 30 秒 → +2cm 稳 30 秒 → 回到 0cm |

> ⚠️ **标定结果不保存**：每次上电后需要在模式 1 重新标定一次（默认零点距离为 7.00cm）。

## 四、接线速查

| 功能 | STM32 引脚 |
|---|---|
| OLED SCL / SDA | **PB8 / PB9**（软件 I²C） |
| 超声波 TRIG / ECHO | **PB0 / PB10** |
| TB6612 AIN1 / AIN2 / PWMA / STBY | **PA4 / PA5 / PA6 / PA7** |
| 按键 KEY1 / KEY2 | **PB1 / PB11**（另一端接 GND） |
| 板载 LED | PC13 |

电源：板子 5V → TB6612 的 `VM` 与 HC-SR04 的 `VCC`；3.3V → TB6612 的 `VCC` 与 OLED 的 `VCC`；**所有 GND 必须共地**。
TB6612 真值表（本工程用到的两行）：

| STBY | AIN1 | AIN2 | PWMA | 电机 |
|---|---|---|---|---|
| 1 | 0 | 1 | 1 | 正转（开泵） |
| 1 | 1 | 1 | 0 | 短路刹车（关泵） |

## 五、编译与下载

1. 用 **Keil MDK5**（ARMCC V5）打开 `control.uvprojx`
2. 编译（F7）—— 应为 `0 Error(s), 0 Warning(s)`
3. 用 ST-Link V2 下载（F8）
4. 上电后：水面停在 0 刻度 → `MODE:1` → 按 KEY2 标定 → 切到 `MODE:3` 或 `MODE:4`

## 七、实现要点（供参考）

- **测距**：`Hcsr04_Measure()` 轮询 ECHO 引脚并用 TIM2（1MHz）计时；带双重超时保护
- **滤波**：环形数组 + 插入排序求中值 → 滑动平均
- **可信度判定**：范围检查 + 最近 N 次读数极差检查 + "预期涨幅"交叉校验
- **控制**：`Control_Update()` 中按模式分支，含提前关泵、盲区估算、注入学习到的上升速度

---

## 八、已知限制

- 水泵工作时水面被搅动，超声波可能短暂失明（此时屏幕显示 `--.--`）
- 装置**没有主动排水能力**，超调后只能靠漏水孔缓慢下降，因此控制策略偏向"宁少补、不过头"
- 建议：进水管贴筒壁、探头下加"静水井"（一小段管子），可显著改善测量稳定性
