第 0 章  先花 1 分钟看懂原理
--------------------------------------------------------------------------------
  容器底下有个小孔一直在漏水。我们要让水面自动升到、并稳定停在刻度线上。

  装置由四部分组成：
    (1) 感知：HC-SR04 超声波模块吊在容器正上方，探头朝下，测量"探头到水面"的距离
             水面越高 → 距离越小 → 液位 = 零点距离 − 当前距离
             （零点距离 = 水面正好在 0cm 刻度时，探头到水面的距离，默认按 8cm 设计）
    (2) 决策：STM32 每 60ms 测一次液位，和目标的 -2 / 0 / +2 比较
    (3) 执行：PA4~PA7 控制 TB6612 电机驱动模块 → 水泵转，往容器里补水（电从面包板 5V 来）
(4) 显示：0.96 寸 OLED 显示液位、目标、水泵状态、保持时间（不再用串口输出）

  控制的核心思想："提前关泵"。
    如果只是"到目标就关泵"，水管里和半空中的水还会继续流进去，水面一定冲过头。
    程序会先算出液面上升速度(cm/s)，再乘上"关泵后水还会流多久"，提前这么多厘米就关泵，
    水面就刚好停在目标上。所以程序里有个参数 PUMP_STOP_LAG_S（默认 0.30 秒）很关键。

1.2 ★引脚数量答疑：只有 1 个 5V、2 个 3.3V、3 个 GND，够吗？
    够，而且你只需要用到【1 个 5V、1 个 3.3V、2 个 GND】，剩下的孔由面包板提供。

    为什么够：面包板的两条电源轨（红线/蓝线）本身就是"一整条相通的导线"，
    你把板子的 1 个引脚接到轨上，这条轨上的几十个孔就全都是这个电压了。
    所以：

      板子 5V   ──1 根线──→  面包板"上排红线"  → 这条线上所有孔都是 5V
                                               （HC-SR04 的 VCC、MOS 模块的 VCC 都从这里取）
      板子 3.3V ──1 根线──→  面包板"下排红线"  → OLED 的 VCC 从这里取
      板子 GND  ──1 根线──→  面包板"下排蓝线"  → 再用 1 根跳线把"上排蓝线"连过来，
                                               两条蓝线就都是 GND 了

    一共只用掉板子上 3 个引脚（想更省事就用 3 个 GND 里的 2 个：一条蓝线各接一个，不接跳线也行）。

    剩下的信号线（OLED 的 SCL/SDA、超声波的 TRIG/ECHO、MOS 的 IN、两个按键）都是
    【一个模块引脚对一个单片机引脚】，直接用母对母杜邦线插，不经过面包板。
    详细接法看图：液位控制_接线图.png 的图②和图③。

4.1 容器（首选方案）
  名称：透明亚克力圆筒（带底板），外径 90mm × 壁厚 3mm × 高 150mm
  淘宝关键词："亚克力管 外径90mm 壁厚3mm 高150mm 带底 透明圆筒"
  参考价：15~25 元（选能"定制切割 + 配亚克力底板"的店，底板要用亚克力胶水粘好不漏水）

  为什么选它：
    · 内径 = 90 − 3×2 = 84mm → 内截面积 A = π×4.2² = 55.4 cm²（直筒，面积恒定，好算）
    · 内径 84mm ≥ 80mm：超声波波束在 6~10cm 距离时约 3~5cm 宽，不会打到筒壁上
    · 高 150mm 够用：底部往上留 60mm 给 0 线，上方还有 70mm 余量

  刻度怎么画（★关键，一定要量准）：
    · 从筒内底部往上量 60mm，在外壁画一条线 = 0cm 线（参考液位）
    · 从 0 线往上量 20mm 画一条 = +2cm 线      （即底往上 80mm）
    · 从 0 线往下量 20mm 画一条 = -2cm 线      （即底往上 40mm）
    · 用油性记号笔 + 钢尺，绕筒画一整圈水平线

  备选方案：透明 PP 塑料量杯 1000mL（上口约 φ120、底约 φ95、高约 165mm，5~12 元）
    优点：随处可买、自带刻度、打孔不易裂；缺点：上宽下窄，截面积随水位变化
    按 0 线处内径 ~φ107（A≈89.9cm²）换算：0cm 处漏速 162mL/min、液位下降 0.030cm/s，
    从 0 降到 -2 约需 78 秒（合格但余量偏小）→ 建议这个容器把孔径改成 Ø3.0mm（约 54 秒）

4.2 漏水孔（具体做法）
  · 位置：0cm 线下方 40mm 处 = 底往上 20mm，即"孔位于 −4cm 高度"
      （考核要求三条刻度都高于漏水孔，这里 -2cm 线比孔高 20mm ✓）
  · 孔径：Ø2.5mm
  · 做法（两种任选）：
      方法A：用 Ø2.5mm 麻花钻头打孔，打完用美工刀把孔口毛刺轻轻刮平（毛刺会让水流不稳）
      方法B（更准）：先打 Ø4mm 的孔，剪一段 10mm 长、内径 2.5mm 外径 4mm 的硅胶管塞进去，
                     管口朝外，四周用热熔胶密封
                     ★塞管子相当于"短管出水"，出水量比薄壁孔大 25~30%（漏得更快），也是合格的
  · 不要做：
      孔径 < 2.0mm：容易堵，而且从 0 降到 -2 会超过考核的 120 秒限时
      孔径 > 3.5mm：漏速接近 320mL/min，对泵要求更高，水面波动也更大

4.3 漏速计算结果（Ø2.5mm 薄壁孔，孔在 −4cm，容器内径 84mm）
  托里拆利公式：Q = 0.62 × 孔面积 × √(2g·h)   （h = 孔上方的水头高度，g = 981 cm/s²）
    孔面积 a = π × 0.125² = 0.0491 cm²；液面下降速度 = 漏水流量 ÷ 55.4 cm²

    ┌───────┬────────────┬─────────────┬──────────────┬─────────────┐
    │ 水位  │ 孔上方水头 │ 漏水流量    │ 液面下降速度 │ 换算        │
    ├───────┼────────────┼─────────────┼──────────────┼─────────────┤
    │ +2cm  │ 6 cm       │ 198 mL/min  │ 0.060 cm/s   │ 3.6 cm/分钟 │
    │  0cm  │ 4 cm       │ 162 mL/min  │ 0.049 cm/s   │ 2.9 cm/分钟 │
    │ -2cm  │ 2 cm       │ 114 mL/min  │ 0.034 cm/s   │ 2.1 cm/分钟 │
    └───────┴────────────┴─────────────┴──────────────┴─────────────┘
  注意：水位越低漏得越慢（水压变小），这是正常物理现象，程序会自动适应。

  ★考核关键时间（五级要求"从 0 降到 -2，限时 120 秒"）：
      从 0cm 降到 -2cm：约 48 秒   ✓ 余量很足
      从 +2cm 降到 -2cm：约 85 秒
      孔径 2.0mm：约 75 秒（仍合格）  孔径 3.0mm：约 33 秒（更快）
    → 结论：孔径控制在 2.0~3.0mm 都能过，Ø2.5mm 最稳。

4.4 ★水泵和供电（按你的泵 + "不额外接电源"的要求重算过）
  你的泵：JT-DC3W-4.5 —— 4.5V、0.18A（0.9W）、最大流量 100 L/H（=1667 mL/min）、最大扬程 0.55m

  换算到你的容器（内截面积 55.4 cm²）：
      100 L/H ÷ 60 ÷ 55.4 = 0.50 cm/s   ← "零扬程"的理论值
      实际要把水从瓶子提到容器上方 10~20cm，流量会小一些，按 0.35~0.50 cm/s 估

  考核要求核对：
      上升段：从 -2cm 补到 +2cm（4cm）限时 60 秒 → 需要净上升 ≥ 0.067 cm/s
      你的泵：0.35 − 0.037（同时还在漏水）≈ 0.31 cm/s → 4cm 只要约 13 秒  ✓✓ 很充裕
    → 结论：这个泵完全够用，甚至偏猛；如果冲过头，用长尾夹把出水管夹扁一点节流。

  接法（★不用另接电源）：
      · 水泵红线 → TB6612 的 AO1；水泵黑线 → TB6612 的 AO2
      · TB6612 的 VM  → 面包板 5V 红线轨（★水泵的电由这里供给）
      · TB6612 的 VCC → 面包板 3.3V 红线轨（模块逻辑电源，必须接 3.3V）
      · TB6612 的 GND → 面包板 GND 蓝线轨
      · AIN1/AIN2/PWMA/STBY → 单片机 PA4/PA5/PA6/PA7（信号线）
    ★泵额定 4.5V、我们给 5V，会稍快一点点（约 10%），完全没问题
    ★0.18A 对 TB6612（连续 1.2A）和面包板（约 1A）都是小意思

  ★三点注意：
    · 潜水泵（IP68）必须整个泡在水源瓶里，绝对不能空转，会烧泵
    · 出水管要贴着筒壁往下流，不要从高处直冲水面（会溅起水花气泡，超声波测不准）
    · 泵的红黑线是裸线头，接 AO1/AO2 时：用"公对母"杜邦线（母头插模块、
      公头和泵线拧紧缠电工胶带），或买两个"免焊接线端子"（¥1~2/个）夹住更牢靠

4.6 买回来先验收漏速（3 分钟，务必做一次）
    1) 容器放桌上，用手指或胶带堵住漏水孔
    2) 加水到 0cm 线
    3) 松手的同时用手机秒表开始计时，眼睛盯水面从 0cm 掉到 -2cm
    4) 用时 40~80 秒 = 完美；80~110 秒 = 偏慢但合格；>120 秒 = 必须扩到 Ø3.0mm；<30 秒 = 太快，重打 Ø2.0mm
    5) 顺手量一下 1 分钟能接多少毫升水（应在 100~250 mL/min）
  ★程序不需要知道漏速，它会边跑边自己学；漏速只影响"能不能在限时内完成"。

5.2 ★接线顺序（一共 18 步、分 4 组，做完一组检查一组）

   【第一组：把四条电源轨搭好】
     1. 板子 5V   → 面包板"上排红线"任意一个孔
     2. 板子 3.3V → 面包板"下排红线"任意一个孔
     3. 板子 GND  → 面包板"下排蓝线"任意一个孔
     4. 用 1 根跳线把"上排蓝线"和"下排蓝线"连起来（共地）
        ★有些面包板的电源轨中间是断开的：用万用表量左右两端通不通，
          不通就再用 1 根跳线把左右两段连起来
     5. 在"上排红线(5V)"和"下排蓝线(GND)"之间并一个 470µF 电容（长脚接 5V）
     ☑ 检查：万用表量"上排红线—下排蓝线"应是 5V；"下排红线—下排蓝线"应是 3.3V

   【第二组：模块的电源（都用公对母：公头插面包板，母头插模块）】
     6.  OLED 的 VCC → 下排红线（3.3V）；GND → 下排蓝线
     7.  HC-SR04 的 VCC → 上排红线（5V）；GND → 上排蓝线
     8.  TB6612 的 VM  → 上排红线（5V）★水泵的电从这里来
     9.  TB6612 的 VCC → 下排红线（3.3V）★必须 3.3V，接 5V 可能驱不动
    10.  TB6612 的两个 GND → 一个接上排蓝线、一个接下排蓝线（更稳）
11. （已取消：不用 USB 转 TTL，这一根 GND 也不用接）

   【第三组：信号线（都用母对母，模块直接插到板子上）】
    12.  OLED：SCL → PB8，SDA → PB9
    13.  超声波：TRIG → PB0，ECHO → PB10（中间可以串一只 1KΩ 电阻做保护）
    14.  TB6612：AIN1 → PA4，AIN2 → PA5，PWMA → PA6，STBY → PA7
    15.  按键：KEY1 一只脚 → PB1，KEY2 一只脚 → PB11；两个按键的另一只脚都 → 蓝线（GND）
16. （已取消：本程序不用串口，跳线不需要接 PA9/PA10）

   【第四组：水泵接到驱动模块上】
    17.  TB6612 的 AO1 → 水泵红线（正极）；AO2 → 水泵黑线（负极）
         ★泵线是裸线头：用公对母杜邦线（母头插模块针，公头和泵线拧紧缠电工胶带），
           或者用"免焊接线端子"夹住。★千万不能接反，接反会倒吸
    18.  把潜水泵整个泡进水源瓶里（★绝对不能露出水面空转）

5.3 电源说明（★不用任何额外电源）
      · 单片机：用 ST-Link 的 USB 线插电脑，或者用手机充电头/充电宝经 USB 线供电
      · 水泵：电走这一路 —— 板子 5V → 面包板上排红线 → TB6612 的 VM → 水泵
      · 面包板的两条蓝线（上排/下排）就是整个系统的"地"，必须用跳线连通
      · 电流只有 0.18A，对面包板（约 1A）和 TB6612（连续 1.2A）都很富余
      · 上电顺序：先插单片机 USB → 等屏幕亮了 → 再把潜水泵泡进水里；
        关的时候反过来（先把泵拿出水面再断电，避免干转）
      · ★如果屏幕在水泵启动瞬间闪一下/重启：换 2A 充电头，或把电容换成 1000µF

【第 1 步】做容器和刻度                                    预计 30 分钟

第 7 章  调试流程（按评分等级一步步验证）
--------------------------------------------------------------------------------
★ 屏幕怎么看（现在只显示 5 个项目，重要的独占一行，中间空行隔开）：

      MODE:1              第0行：当前模式号（1~4），按 KEY1 切换
      LEVEL: +0.12 cm     第2行：液位读数（最重要）
      PUMP : ON           第4行：水泵开(ON)还是关(OFF)
      HOLD : 12.3 s       第6行：已经稳定保持了多少秒（考核要连续 15/30 秒）
      MARK : 0CM          第7行：液位落在哪条刻度线上（0CM / -2CM / +2CM / ---）

  ★四个模式分别管什么（KEY1 循环切换）：
      模式1  标定零点 —— 按一下 KEY2，就把此刻的水面记成 0cm（标定时自动停泵）
      模式2  手动控制 —— 按一下 KEY2 开泵、再按一下关泵（一级评分点）
      模式3  自动保持 —— 自动把液位稳定在 0 位（三级、四级评分点）
      模式4  五级自动 —— 全自动：稳住 0 → 降到 -2 → 升到 +2（五级评分点）

  另外两种情况：
    · 开机直接进模式1，没有欢迎动画。
    · 超声波没接好时，LEVEL 行会显示 "SENSOR ERR"，MARK 行显示 "---"，
      这是程序的安全保护（不会盲目补水）。
--------------------------------------------------------------------------------
  ◆ 一级：验证水泵能开能停
      KEY1 按到屏幕最上面一行显示 "MODE:2"（这就是手动模式）
      按一下 KEY2 → 水泵转（板载 LED 同时亮），屏幕 PUMP 显示 ON
      再按一下 KEY2 → 水泵停，屏幕 PUMP 显示 OFF

  ◆ 二级：验证液位识别
      KEY1 按到 "MODE:3"（自动保持在 0 位）
      把水面分别停在 -2cm、0cm、+2cm 三条线上，每次等 2 秒
      看屏幕上的两行：
        "LEVEL: +2.01 cm"  ← 液位读数
        "MARK : +2CM"      ← 判定落在那条刻度上（应分别显示 -2CM / 0CM / +2CM）

  ◆ 三级：验证自动补水 + 稳定保持
      KEY1 按到 "MODE:3"，把水面弄到 -2cm 附近，然后不要再动水
      水泵自动开启（STATE:FILL）→ 到达后关闭 → STATE 变成 HOLD，HOLD 秒数一直往上涨
      按你这套硬件仿真：几秒到位，之后一直保持在 ±0.15cm 内

  ◆ 四级：验证被抽水后自动恢复
      等三级稳定后（HOLD 涨到 30 秒以上），用注射器抽走约 1cm 水位的水
      系统会自动补回 0cm 并继续稳定保持（仿真：约 2 秒恢复）

  ◆ 五级：验证全自动切换
      KEY1 连按，直到最上面一行显示 "MODE:4"（五级自动流程），之后完全不要碰按键：
        S0：先把液位稳定在 0cm（稳住 30 秒）
        S1：目标切到 -2cm —— 泵不工作，靠漏水自然降下去（约 35 秒），到位后稳住
        S2：目标切到 +2cm —— 泵自动补水上去（约 9 秒），到位后稳住
        S3：任务完成，一直保持在 +2cm
      屏幕最上面一行会显示当前第几步和当前目标（例：AUTO S1 -> -2.00）

◆ （串口部分已删除 —— 本程序不再通过串口输出数据）

--------------------------------------------------------------------------------
  现象                          可能原因 / 解决办法
  ------------------------------------------------------------------------------
  OLED 全黑不亮                 ① SCL/SDA 接反了（交换 PB8/PB9 试试）
                                ② VCC 接错（OLED 必须接 3.3V 那条红线）
                                ③ 面包板电源轨中间断开 → 用跳线把左右连起来

  屏幕亮但 LEVEL 永远是 +0.00  ① ECHO 没接到 PB10 ② TRIG 没接到 PB0
                                ③ 超声波没供电（VCC 要接 5V 那条红线）

  超声波读数偶尔离谱            ① 程序已做"中值+滑动平均"两级滤波和范围检查，会自动丢掉坏数据
                                ② 触发脉冲已按同类项目做法改成"先拉低2µs再拉高12µs"，触发更可靠
                                ③ 传感器支架没固定牢 → 加固
                                ③ 水面泡沫太多 → 等泡沫散了再测

  水泵一转，LEVEL 就跳到      ★这是最典型的一个坑，程序已经做了三层防护，
  -20~-40，而且泵一直抽不停    但硬件上也建议这样改善：
                                ① 出水管口贴着筒壁、顺着壁往下流，不要对着水面冲
                                ② 探头正下方套一小段管子（内径 30~40mm、长 40mm 左右）
                                   做成"静水井"，水面在里面是平静的，测出来特别稳
                                ③ 5V 和 GND 之间加 470µF 电容（泵启动时电压会抖）
                                ④ 探头尽量离进水口远一点、离水面近一点（10cm 内最好）
                                原理：水泵把水面搅动后，超声波的回波会丢，探头会打到
                                      桌子、地面上，测出 30~50cm 的假距离，程序就会
                                      以为"还差得远"而一直抽水（旧版程序就会抽到溢出）。
                                程序里的四层防护：
                                  第1层 范围检查：距离超出"零点±10cm"直接丢掉
                                  第2层 跳变检查：相邻两次跳超过 3cm 直接丢掉
                                  第3层 补水量估算：实在测不准时，按已知的上升速度
                                        推算补了多少水，到量了就正常关泵（不会一直抽）
                                        这时屏幕上显示的是"估算液位"，不会闪 SENSOR ERR
                                  第4层 承认现实：连续 5 次读到同一个"跳变"数据 → 接受它
                                        （防止考官一次抽走很多水后程序卡在报警状态）

  按键没反应                    ① 接错脚（KEY1 是 PB1，KEY2 是 PB11，不要对调）
                                ② 按键另一只脚忘了接 GND
                                ③ 用万用表通断档量按键：按下应导通、松开应断开

  水泵不转                      ① TB6612 的 VM 没接到面包板 5V 红线轨
                                ② TB6612 的 GND 没接到蓝线轨（地没通）
                                ③ TB6612 的 VCC 没接 3.3V（接 5V 时 3.3V 信号可能驱不动）
                                ④ 4 根控制线接错脚（AIN1→PA4 AIN2→PA5 PWMA→PA6 STBY→PA7）
                                ⑤ 泵坏了/卡住 → 直接给泵接 5V 试一两秒
                                ⑥ 潜水泵没泡在水里

  水泵一直转不停                ① 程序有保护：传感器连续 1.5 秒测不到就会强制停泵
                                ② 如果一直转，说明模式在 2（手动） 且手动开着了 → KEY1 切模式
                                ③ 4 根控制线有虚接

  水泵方向反了（倒吸）          泵的红黑线接反了 → 把 AO1/AO2 上的两根线对调

  单片机反复重启（屏幕反复闪）  ① 水泵启动瞬间把 5V 拉低了 → 在 5V 轨和 GND 轨之间并 470µF 电容
                                ② 还不行就换 2A 的充电头，或把电容换成 1000µF

第 11 章  考核当天的操作流程（打印出来照着做）
--------------------------------------------------------------------------------
  0. 出发前：带备件（备用超声波、备用按键、杜邦线、万用表、胶带、注射器、电池）
  1. 摆好容器 → 加水到 0cm 线附近 → 水源瓶加满（或做好漏水回收）
  2. 先插单片机 USB → 等屏幕出现主界面
  3. 再把潜水泵放进水源瓶里泡好 → 开泵电源
  4. 把水面调到正好 0cm 线 → 切到模式1 按一下 KEY2 标定 → 确认 LEVEL 在 +0.00 附近
  5. 考官说开始后，按等级操作：
       一级：KEY1 切到 MODE:2 → 按 KEY2 开泵 → 报告"水泵已启动"
             → 再按 KEY2 关泵 → 报告"水泵已停止"
       二级：把水面依次停在 -2 / 0 / +2 三条线上，报出屏幕上的 LEVEL 和 MARK
       三级：KEY1 切到 MODE:3，把水面弄到 -2 附近，让它自己补到 0，
             观察 HOLD 计时不断增长
       四级：保持三级状态，请考官抽水，观察自动恢复到 0 并继续保持
       五级：KEY1 切到 MODE:4，然后双手离开键盘，全程自动完成
  6. 全程盯屏幕：FILL=正在补水，HOLD=已稳住（秒数在涨），HIGH=偏高在等漏下去，LOW=偏低待补
  7. 出现异常第一时间按 KEY1 切到 MODE:2（手动） 并按 KEY2 关泵，保护现场
